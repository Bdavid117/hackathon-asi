Medido contra la API real (Sonnet 5.5 y Opus 5.5) con 750 reportes sintéticos con texto · docs/resultados/modelo-real.md

Un minuto y medio. El modelo es una opción del agente de triaje, apagada por omisión. Con ella, sobre 750 reportes sintéticos con texto, el recall de P1 sube del 85,4 % al 96,0 % (Sonnet 5.5, esfuerzo bajo; Opus 5.5 llega al 98,5 %), sobre todo en paráfrasis y reportes sin banderas. A cambio se revisan algunos reportes de más: 10 P2 que el modelo sube a P1 (Opus, 24). El modelo nunca baja una urgencia —lo impide el piso por reglas— y sólo sube con una cita literal verificada; no tiene herramienta de despacho. Ninguna de las 749 respuestas útiles pasó de los 8 s del plazo del nodo (p95 4,4 s) y cada reporte cuesta unos 0,0024 USD. Con doce textos que dan instrucciones maliciosas, en español y en inglés, el modelo no se dejó manipular. Si no responde, el nodo sigue con reglas.
